# Evaluacion-IR-Unidad-IV-Naranjo-Anderson

Prueba práctica de la Unidad IV de Ingeniería de Requisitos.

## Archivo principal
`main.tex`

## Compilación con MiKTeX / VS Code
El proyecto incluye `.vscode/settings.json` para que LaTeX Workshop compile directamente con `pdflatex` y no dependa de `latexmk`.

En VS Code:
1. Abra la carpeta completa del proyecto.
2. Abra `main.tex`.
3. En LaTeX Workshop seleccione la receta `pdflatex x2` o use **Build LaTeX project**.

También puede compilar desde la terminal:

```bash
pdflatex main.tex
pdflatex main.tex
```

## Estructura
- `main.tex`: documento editable.
- `main.pdf`: PDF compilado.
- `figuras/`: capturas del SGA y diagramas P1, P2 y P3.
- `.vscode/settings.json`: receta de compilación para VS Code + MiKTeX.
